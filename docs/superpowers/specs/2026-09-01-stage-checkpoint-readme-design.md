# 阶段版本记录与 README 更新设计

## 目标

把当前已经上线并完成验证的学习闭环记录为一个阶段性完成版本，让 GitHub 访客能够从 README 直接了解当前产品能力、实际入口和验证状态。

## README 调整

- 在项目介绍之后新增“当前阶段版本”章节，明确这是阶段性完成状态，不等同于正式稳定版发布。
- 概括当前两大入口：知识点提取与学习空间。
- 记录学习书创建、默认全选、进入学习、进度保存、修改和删除能力。
- 说明已开始学习的学习书修改时保存为新版本；删除时会二次确认并清理相关学习数据。
- 写入本次全量验证结果：TypeScript 790 项、Python 393 项通过。
- 更新“它能做什么”“第一次使用”和安装确认清单，使原有说明与当前界面一致。

## 版本与发布边界

- 保持包版本 `0.0.5` 不变。
- 不创建 GitHub Release 或 Git 标签。
- README 与设计说明作为一个文档提交推送到现有 `origin/main`。
- 不修改功能代码、实际数据库或本机安装数据。

## 验证

- 检查 README 中的入口名称、操作路径和数据行为与当前实现一致。
- 运行 Markdown 链接/引用的静态检查；若仓库没有专用文档检查命令，则使用仓库现有构建作为最低验证。
- 推送前确认工作区仅包含本次文档修改，并保留用户已有的 `.superpowers/` 未跟踪目录。
