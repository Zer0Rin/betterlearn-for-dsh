## 右侧浮动工作台

客户端入口从 `conversation.view` / `conversation.input.dock` 调整为直接挂载在 `document.body` 的独立 React root。页面加载时只显示屏幕右侧的 BetterLearn 竖向按钮，点击后展开 fixed 工作台，不改变 DSH 对话区宽度，也不阻止用户继续操作 DSH 本体。浮窗订阅当前会话，会话切换时自动显示对应 BetterLearn 任务；刷新后仍默认收起，已有任务继续由原 sessionStorage 规则恢复。

首轮尺寸基线按流程变化：空状态 420px、导入 560px、处理 520px、审核最多 1080px、结果 600px，最大高度为视口减 32px并在内部滚动；680px及以下使用全屏。当前目标是先保证完整内容与并行对话体验，精确宽高留给视觉验收反馈继续调整。
