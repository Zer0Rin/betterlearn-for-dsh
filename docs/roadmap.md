# BetterLearn for DSH 路线图

本路线图只描述独立 DSH 插件主线，不继承旧 Nobei 的企业产品化批次或 Claude Code sidecar 方案。

## P0：独立仓库收口

- 完成独立构建、测试与 tarball 验证；
- 固定 DSH rc.7 依赖与基础迁移来源；
- 保证默认验证不依赖旧仓库、旧数据库和历史 evidence。

## P1：状态同步体验

- Core 生成完成后让 WebUI 自动进入审核状态；
- 保留短轮询兜底，避免伪造进度；
- 明确失败、重试和恢复文案。

## P2：正式数据模型决策

- 决定 BetterLearn 是保持独立产品数据库，还是与旧 Nobei 学习数据合并；
- 若合并，先用只读实测确定旧证据的唯一命中、多命中、无命中和文件缺失分布；
- 再设计单一、有序、可回滚的迁移，而不是直接拼接旧方案。

## P3：能力扩展

- PDF 与结构化解析；
- 长文档分块和 L2/L3 路由；
- 多证据知识点与文档级绝对坐标；
- 基于真实分布改进重复 quote 的消歧体验。

## P4：交付

- 普通用户的安装、启动、升级与卸载流程；
- 数据备份和恢复演练；
- DSH rc.8 独立升级演练；
- 稳定版本发布前的产品体验与错误提示收口。
