# BetterLearn for DSH 路线图

本路线图只描述独立 DSH 插件主线，不继承旧 Nobei 的企业产品化批次或 Claude Code sidecar 方案。

## P0：独立仓库收口（已完成）

- 独立构建、测试与 tarball 验证通过；
- 建立 DSH rc.7 开发基线，运行兼容性后续由 P4 实测；
- 默认验证不依赖旧仓库、旧数据库和历史 evidence。

## P1：状态同步闭环（已完成）

- Core 生成完成后 WebUI 自动进入审核界面；
- 短轮询作为同步机制：1→2→4→8 秒退避，有新事件即重置回 1 秒；
- 失败、重试和恢复的基础文案已具备。

## P1.1：体验优化（已完成）

- Host 在生成结果写入 Core 后通过 SSE 发送状态变化提示，唤醒现有 pollRun，立即读取状态并进入审核；
- 1→2→4→8 秒轮询兜底保留；SSE 断开静默回退，进入审核/终态、切换任务或卸载时释放订阅；
- 失败、重试和恢复文案已统一审计；审核失败页补上“重新连接”，复用既有幂等审核恢复；
- 仅新增通知通道，不新增业务状态副本、Core 轮询或 Python RPC。实现约定见 [架构](architecture.md)，定向验证见 [验证说明](validation.md)。

## P2：独立产品数据模型（已完成）

- 产品自有11表，去掉旧v8、p1前缀、import_jobs双投影和单块chunks正文；
- 不可变候选与审核定稿分离，全部证据使用文档绝对Unicode字符坐标；
- 写事务维护计数，读取不重算原始输出、证据或历史账本；
- 干净重建，无旧数据迁移，原公开快照字段保持兼容。

设计稿见 [数据模型设计](data-model.md)。

## P3：能力扩展（已完成）

- 有文字层PDF的只读解析与预览，扫描/加密/损坏文件明确提示；
- 长文物理分块，实际执行L2语义规划与分组、L3重叠容器与边界提取；
- 跨批次同一知识点合并多证据，重复quote以范围与相邻上下文消歧；
- 真实DSH浏览器覆盖Unicode、80,006字符尾段、多证据切换与审核；
- 正文512KiB、PDF5MiB，不支持OCR；模型语义质量不由fake验收担保。

## P4：交付（已完成）

- tarball内CLI支持安装、前台启动、先备份再升级、保留数据卸载；
- 在线SQLite备份、离线恢复前保存现库，运行中恢复明确拒绝；
- 真实DSH rc.8独立安装与不同版本插件包升级演练通过；
- 重启、恢复、升级、卸载的数据结果逐项核对通过；
- 安装说明与限制已记录；未发布npm、未推送远程，也不新增后台服务。

## P5：学习书与学习空间（已完成）

- 将审核通过的知识点整理为学习书，默认全选并允许用户调整；
- 支持学习书创建、修改、版本化与二次确认删除；
- 提供学习书架和学习空间，显示课程进度与掌握度；
- 已开始的学习书修改时生成新版本，保留原课程与进度。

## P6：真实学习闭环 V1（已完成）

- 冻结正式知识点及其来源证据，生成陈述辨析与证据定位题；
- 正确答案只保存在 Python Core，浏览器只接收 learner-safe 数据；
- Core 完成确定性判分与幂等作答；
- 持久化错误补救、证据复测、掌握度和下一次复习时间；
- Schema v2 在原 11 张提取与审核表之外增加 5 张学习表。

## P7：个性化学习（规划中）

- 初始诊断与学习目标；
- 更丰富的客观题与代码题；
- 模型生成教学内容与开放题评价；
- 更完整的复习调度。

## 对话知识提取优化（已实现，待实际界面反馈）

- 新建任务先选择知识来源，DSH 历史对话作为独立入口；
- 用户可搜索并多选相关普通对话，合并为一个提取任务；
- 正式提取前强制展示完整合并正文和调用计划，内容变化后要求重新预览；
- 只纳入用户正文与 DSH 可见文字回答，排除系统提示、推理、工具、插件上下文和子 Agent 内容；
- 最多选择50个对话，合并正文上限512KiB，不静默截断。

2026-08-31验收标准与结果见 [验证说明](validation.md) 和 [交付记录](delivery-plan.md)。历史真实模型、授权批次和provider账本封存，本轮零真实模型调用。
